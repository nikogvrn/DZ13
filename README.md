# Домашнее задание. Вариант 16
## Условие задачи

Пользователь вводит название упражнения, число подходов и повторений в каждом подходе. Программа добавляет запись в файл `workout.log` в формате:

```text
2026-11-16 | Приседания | 4x15 | всего: 60
```

Общее количество повторений для упражнения — произведение числа подходов на число повторений. При завершении программы в файл добавляется сумма повторений за текущую сессию.

## 1. Алгоритм и блок-схема

### Алгоритм

**Начало**

1. Получить текущую дату в формате `ГГГГ-ММ-ДД`.
2. Обнулить сумму повторений за сессию.
3. Открыть файл `workout.log` для добавления записей.
4. Ввести название упражнения.
5. Если введено `STOP`:
   - вывести сумму повторений за сессию;
   - добавить итоговую строку в файл;
   - завершить программу.
6. Ввести число подходов и повторений в подходе.
7. Вычислить общее количество повторений:  
   `всего = подходы × повторения`.
8. Прибавить результат к сумме за сессию.
9. Записать дату, упражнение, подходы, повторения и их сумму в файл.
10. Повторить ввод.

**Конец**

## 2. Реализация программы

Программа написана на языке C. Для получения текущей даты используются функции `time` и `strftime`, для работы с файлом — `fopen` и `fprintf`. Записи добавляются в `workout.log`, поэтому предыдущие данные сохраняются.

Название упражнения считывается как одно слово. Для завершения ввода программа ожидает слово `STOP` в верхнем регистре.

## 3. Результаты работы программы

Пример работы программы:

```text
ВВЕДИТЕ ВИД УПРАЖНЕНИЯ: Приседания
ВВЕДИТЕ КОЛ-ВО ПОДХОДОВ: 4
ВВЕДИТЕ КОЛ-ВО ПОВТОРЕНИЕ: 15
2026-11-24 | Приседания | 4*15 | всего: 60
РЕЗУЛЬТАТЫ ЗАПИСАННЫ В ФАЙЛ: workout.log

ВВЕДИТЕ ВИД УПРАЖНЕНИЯ: STOP

ПОВТОРЕНИЙ ЗА ВВСЕ ВРЕМЯ: 60
```
